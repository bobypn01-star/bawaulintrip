Kebijakan Privasi dan Refund

Terakhir diperbarui: 4 November 2026 · Dokumen versi 1.7. Teks yang sama tersedia di aplikasi (Akun › Info Umum) mulai v5.35.0.

Data trip dan keuangan Anda disimpan di HP Anda sendiri dan tidak dikirim ke server penjual, kecuali dua hal di bawah: Pendaftaran Online dan Trip bersama.

Yang dikirim ke server lisensi: kode perangkat, versi aplikasi, token pasang acak, alamat asal aplikasi, dan penanda teknis keaslian kode. Tujuannya hanya memeriksa status lisensi dan menjaga agar satu lisensi dipakai di satu HP.
Server juga mencatat kejadian teknis (misalnya kode dipakai di dua HP). Saat Anda membeli paket, server mencatat pesanan: kode perangkat, paket dan periode, nominal, status dan waktu pembayaran, metode bayar, serta nama, nomor WhatsApp, dan email bila Anda mengisinya (email boleh kosong). Nama dan nomor WhatsApp dipakai hanya untuk bantuan, bukti pembelian, refund, dan pembukuan penjual; Anda dapat meminta keduanya dihapus atau dianonimkan (nominal transaksi tetap disimpan untuk pembukuan). Pembayaran diproses oleh Midtrans; aplikasi dan server tidak menyimpan nomor kartu atau akun e-wallet Anda. Data pesanan dipakai untuk menerapkan paket, bantuan, refund, dan pembukuan penjual. Perangkat Basecamp yang tidak dibuka lagi selama 90 hari dihapus dari server (data trip Anda tetap di HP). Saat aplikasi pertama kali dibuka, server juga mencatat cara aplikasi dipakai (aplikasi terpasang atau dibuka di browser), kode ajakan teman bila Anda membuka aplikasi lewat tautan ajakan, nama panggilan bila Anda mengisinya (opsional), dan perkiraan negara dari jaringan. Saat Anda menekan tombol unduh APK di website, server mencatat waktu, jenis perangkat secara kasar, dan sidik acak alamat IP yang berganti tiap hari dan dihapus setelah 7 hari. Data ini dipakai untuk statistik penggunaan, bukan untuk mengenali Anda.
Server juga mencatat paket Anda (Basecamp, Sabana, Puncak, atau Edelweis), tanggal berakhirnya, dan penanda waktu pencabutan bila ada. Ini hanya penanda; isi trip tidak dikirim, kecuali trip yang Anda bagikan lewat Trip bersama (lihat bagian Trip bersama di bawah).
Pendaftaran Online: saat calon peserta mengisi formulir, nama, nomor WhatsApp, meeting point, jawaban alergi makanan, dan catatan mereka dititipkan sementara di server bawaulin.trip dan dikaitkan dengan kode perangkat Anda. Setelah aplikasi Anda mengambilnya, data itu dihapus dari server. Data yang belum diambil dihapus otomatis setelah 30 hari, atau saat Anda menutup pendaftaran. Penjual tidak memakai data ini selain mengantarkannya kepada Anda. Alamat IP pengirim hanya dipakai dalam bentuk sidik acak untuk membatasi kiriman berlebihan. Anda bertanggung jawab meminta izin peserta; info alergi termasuk data kesehatan.
Notifikasi: bila Anda mengaktifkan notifikasi pendaftar baru, server menyimpan alamat langganan notifikasi dari HP atau peramban Anda (maksimal 5 per kode) untuk mengirim pemberitahuan. Anda dapat mematikannya kapan saja di halaman Pendaftaran.
Lapor masalah lewat WhatsApp hanya mengirim info teknis dan hanya terkirim bila Anda menekan kirim di WhatsApp. Bila Anda memilih Kirim lewat aplikasi (opsional, dengan persetujuan Anda), kategori, pesan, kontak (boleh kosong), versi aplikasi, mode tampil, dan kode perangkat dikirim ke server penjual dan disimpan sampai 180 hari setelah laporan ditandai selesai; tanpa lampiran dan tanpa data trip. Penjual dapat menganonimkan laporan atas permintaan Anda. Cadangan data berupa berkas yang Anda unduh dan simpan sendiri.
Pengumuman dari penjual diterima lewat balasan pemeriksaan lisensi yang sudah ada; tidak ada data tambahan yang dikirim untuk itu. Untuk menahan kiriman berlebihan, penjual dapat memblokir sementara sebuah sidik acak alamat jaringan atau alamat asal aplikasi (hanya manual dan berbatas waktu; alamat IP mentah tidak disimpan). Penjual tidak mengumpulkan kota atau provinsi Anda.
Aplikasi tidak memakai iklan atau pelacak pihak ketiga. Aplikasi dihosting di GitHub Pages dan server berjalan di layanan hosting pihak ketiga (Supabase); keduanya dapat mencatat akses jaringan sesuai kebijakannya sendiri.
Trip bersama (hanya bila Anda membuat atau bergabung ke trip bersama; trip sendiri tetap di HP Anda): isi bagian trip yang disinkronkan disimpan di server bawaulin.trip supaya sampai ke HP anggota. Isinya bisa memuat nama peserta, jumlah uang, dan bagian lain yang diizinkan pemilik. Server juga menyimpan pasangan trip dan kode perangkat anggota, nama kartu trip, nama tampilan anggota, izin tiap anggota, dan riwayat perubahan (siapa mengubah apa, kapan, nilai lama dan baru). Kontak peserta (ponsel dan catatan) punya izin terpisah dan bawaannya mati; kontak dan catatan peserta tidak dicatat di riwayat. Foto bukti nota tidak ikut dikirim.
Lama penyimpanan trip bersama: riwayat perubahan dihapus setelah 180 hari. Data trip di server dihapus 180 hari setelah trip ditutup (Tutup Buku) atau setelah sinkron berhenti karena paket pemilik habis lewat masa tenggang. Pemilik dapat menghapus trip dari server kapan saja. Anggota yang dicabut atau keluar tidak lagi mengirim atau menerima perubahan; salinan di HP tiap anggota tetap ada di HP itu sampai pemiliknya menghapusnya.
Tanggung jawab data peserta di trip bersama: pemilik trip menentukan data apa yang dimasukkan dan siapa yang boleh melihat atau mengubahnya, dan bertanggung jawab meminta izin peserta; bawaulin.trip menyimpan dan meneruskan data itu atas permintaan pemilik. Administrator bawaulin.trip dapat menangguhkan trip bersama atau memindahkan pemiliknya (misalnya bila HP pemilik hilang).
Penjual tidak menjual data Anda. Untuk meminta data pembelian Anda dihapus, hubungi penjual lewat WhatsApp.

Kebijakan pengembalian dana

Ringkasnya

  • Sabana, Puncak, dan Edelweis adalah produk digital. Pembayaran yang sudah diterima pada dasarnya tidak dikembalikan.
  • Uang dikembalikan bila paket gagal aktif karena kesalahan di pihak kami, misalnya pembayaran sudah terverifikasi tetapi paket tidak diterapkan dan tidak bisa diperbaiki.
  • Tidak berlaku bila penyebabnya di sisi pembeli: salah ketik kode perangkat, HP tidak cocok, atau berubah pikiran.
  • Pencabutan karena pelanggaran syarat tidak disertai pengembalian uang.
  • Cara mengajukan: hubungi kami lewat WhatsApp dengan nomor pesanan atau bukti pembayaran.

Bunyi lengkap, sama dengan pasal 10 Syarat & Ketentuan:

10. Harga dan pengembalian uang: harga mengikuti yang tertera di halaman penjualan pada saat Anda membeli. Sabana, Puncak, dan Edelweis adalah produk digital, jadi pembayaran yang sudah diterima tidak dikembalikan. Pengecualian: bila aplikasi gagal diaktifkan karena kesalahan di sisi penjual (misalnya kunci atau paket tidak diterbitkan setelah pembayaran terverifikasi, atau aplikasi tidak bisa diaktifkan akibat kesalahan server atau penjual dan tidak dapat diperbaiki), uang dikembalikan. Pengecualian ini tidak berlaku bila penyebabnya di sisi Anda, misalnya salah mengetik kode, HP tidak cocok, atau berubah pikiran. Pencabutan karena pelanggaran (pasal 5) tetap tanpa pengembalian uang. Untuk mengajukan, hubungi penjual lewat WhatsApp dengan bukti pembayaran.
